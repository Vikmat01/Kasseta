КАССЕТА — музыкальный плеер для NextUI (TrimUI Brick, Brick Pro, Smart Pro)

УСТАНОВКА
Скопируйте папку Tools из архива в корень карты памяти (рядом с папками Roms и Bios).
Должно получиться: /Tools/tg5040/Kasseta.pak/
Приложение появится в NextUI в разделе Tools.

МУЗЫКА
Кладите файлы MP3, FLAC, OGG (Vorbis) или WAV в любые папки на карте.
Плеер сам находит их, группирует по исполнителям и альбомам (по тегам,
а если тегов нет — по названиям папок и файлов) и показывает обложки:
встроенные в файл или картинку cover.jpg / folder.jpg / front.jpg в папке альбома.
Папки Roms, Bios, Saves, Emus, Tools и скрытые не сканируются.
Свои исключения можно дописать в skip.txt.
Первый запуск сканирует всю карту, дальше библиотека открывается сразу
и тихо обновляется в фоне.

УПРАВЛЕНИЕ
Библиотека:  крестовина — выбор, A — открыть/играть, B — назад,
             L1/R1 — вкладки, Y — перемешать, X — экран плеера,
             SELECT — пауза, START — меню
Плеер:       A — пауза, L1/R1 — предыдущий/следующий трек,
             влево/вправо — перемотка, Y или вверх/вниз — кассета/CD,
             X — перемешивание, SELECT — режим повтора, B — назад
Везде:       L2/R2 — предыдущий/следующий трек,
             POWER — выключить экран (музыка продолжает играть),
             MENU — выход

При выходе из приложения музыка останавливается: NextUI запускает
одно приложение за раз. Позиция сохраняется и восстанавливается
при следующем запуске.

Журнал ошибок: /.userdata/tg5040/logs/Kasseta.txt
